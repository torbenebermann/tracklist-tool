# 🎧 Tracklist Tool

**Tracklist Tool** is a lightweight, privacy-focused web application designed for DJs to instantly convert Rekordbox history exports into clean, numbered tracklists. Perfect for SoundCloud descriptions, YouTube chapters, or 1001Tracklists.

## 🚀 How to use
1. **Sync:** In Rekordbox, right-click your USB and select `Update Collection`.
2. **Export:** Go to the Global `History` tab, right-click your session, and choose `Export a playlist to a file` -> `M3U8`.
3. **Convert:** Drop the `.m3u8` file into **Tracklist Tool**.
4. **Copy:** Click the copy button and paste directly into SoundCloud.
